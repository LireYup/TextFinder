# TextFinder Minecraft Mod

TextFinder is a Fabric mod for Minecraft 1.21.7~1.21.11 that helps players search through text on signs more efficiently. Tired of manually scrolling through multiple signs to find specific text? This mod makes it easier!

# Usage

Add 3 commands to game
- /tf <keyword> ←start to search
- /td <page number> ←display the search result
- /trf <anotherkeyword> ←search again among the signs already founded
